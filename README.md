# Breast Cancer Tumor Size Prediction

## Project Overview
This project predicts breast cancer tumor size using Machine Learning with Python.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Files
### main.py
Main program file for data processing, training, and prediction.

### Breast_Cancer-selected-columns (1).csv
Dataset used for training the model.

### test_data.csv
Sample data used for testing.

### cancer_model.pkl
Saved machine learning model generated after training.

## How to Run

1. Install libraries:
bash
pip install pandas scikit-learn joblib


2. Run the project:
bash
python main.py


## Output
- Trained prediction model
- Model saved as cancer_model.pkl
